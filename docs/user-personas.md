# Workspace Flow User Personas

## Persona 1: The Multi-Project Developer

**Profile**: A developer managing 2-8 active, dormant, or experimental projects.

**Goals**:

- Resume a project without rereading the entire codebase
- Capture ideas and technical decisions in seconds
- Identify which project needs attention first

**Pain Points**:

- Project intent is scattered across commits, chats, and memory
- Generic analysis warnings lack project context
- Open work does not explain its rationale

**Needs**:

- Private project memory and low-friction note capture
- User-controlled AI enrichment
- Explainable findings and comparable health trends

## Persona 2: The Technical Lead

**Profile**: A technical lead overseeing several repositories without time to inspect each one deeply.

**Goals**:

- Compare health trends using evidence
- Preserve architectural trade-offs
- Prioritize technical investment

**Pain Points**:

- Repository status is difficult to compare consistently
- Important decisions disappear as context changes

**Needs**:

- Cross-project scores and trends
- Findings with severity, location, evidence, and recommendation
- Decision history connected to diagnosis results

## Persona 3: The Returning Maintainer

**Profile**: A developer returning to a project after weeks or months away.

**Goals**:

- Reconstruct decisions and unfinished work
- Find the next useful action quickly
- Understand whether the project is healthier or riskier

**Pain Points**:

- Context switching consumes the first session back
- Technical debt is difficult to distinguish from deliberate trade-offs

**Needs**:

- Project timeline with notes and decisions
- Tasks linked to their originating context
- Transparent score changes

## Persona Prioritization

| Persona | MVP Priority | Primary Value |
|---------|--------------|---------------|
| Multi-Project Developer | Primary | Capture and recover project context |
| Technical Lead | Secondary | Compare health and prioritize repositories |
| Returning Maintainer | Primary scenario | Resume work with minimal reconstruction |
