# Workspace Flow Success Metrics (KPIs)

## MVP Success Metrics

| Metric | Target | Measurement Method |
| ------ | ------ | ------------------ |
| Project resumption rate | 60% of returning users open a project workspace within 2 minutes | Product analytics |
| Context capture rate | 50% of active users create at least one note per week | Note events |
| Note-to-action rate | 30% of enriched notes are accepted as tasks or decisions | Enrichment events |
| Diagnosis completion rate | 90% of consented analysis runs complete successfully | Analysis telemetry |
| Finding explainability | 100% of displayed findings include evidence and recommendation | API validation |
| Score trust | 70% of tested users can explain a score change | Usability testing |
| Week 1 retention | 50% of new users return to a project workspace | Activity logs |
| Data privacy incidents | 0 unauthorized source disclosures | Security monitoring |
| Core workflow accessibility | 100% of MVP journeys keyboard operable | Accessibility testing |
